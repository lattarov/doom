#+title: :private work
#+subtitle: Everything that only makes sense on the work machine

* Description
Work-only tools and settings. =init.el= enables this module only when
=vlv-env-work-p= is non-nil, i.e. under WSL:

#+begin_src emacs-lisp
:private
(:if (vlv-env-work-p) work)
#+end_src

It provides:
- =clang= as the org-babel C/C++ compiler;
- a TightVNC machine menu (=C-c v=);
- launching Wind River Workbench 3 / 4 (=SPC o W= / =SPC o w=);
- [[https://github.com/jthaman/consult-everything][consult-everything]] for Windows' Everything search (=SPC s E=);
- =vlv-work-gen-payfit-report=, the monthly Payfit expense comment;
- daily reminders through =alarm-clock=;
- =robot-mode= and =robot-log= for Robot Framework.

* Configuration
** TightVNC password
There is no hard-coded password: =tightvnc= looks it up in auth-source, e.g. in
=~/.authinfo.gpg=, and prompts for it when there is no entry:

#+begin_example
machine vnc-work login admin password <secret>
#+end_example
